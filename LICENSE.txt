This skill distills patterns from four open-source agent harnesses studied
in the book "Agent Harness Architecture Patterns":

- Codex (https://github.com/openai/codex), Apache-2.0
- Claude Code (closed-source, expanded reverse-engineered build)
- OpenClaw (open-source community fork)
- Hermes Agent (https://github.com/NousResearch/Hermes-Agent), Apache-2.0

The code patterns described in this skill are observations about engineering
choices; the actual implementations remain the copyright of their respective
